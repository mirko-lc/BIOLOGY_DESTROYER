Last step: upload it to GitHub

  1. Open your repository on github.com.
  2. Click Add file → Upload files and drag in the index.html you just downloaded. Check the name is exactly index.html; if your computer saved it as "index (1).html", rename it first.
  3. Click Commit changes. GitHub replaces the old file.
